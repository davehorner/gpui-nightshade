# Included model assets

`AnimatedMorphCube.glb` is the original Khronos sample asset (6,752 bytes).

Copyright 2017, Public. Microsoft created the model. Distributed under
[Creative Commons Zero v1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/legalcode).

Source and credits: [Animated Morph Cube](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/AnimatedMorphCube).

Other model downloads stay in the ignored `target` cache. Their original model
metadata and source license/credit pages apply. Bundled Nightshade skeleton
fallbacks retain their existing upstream distribution and licenses.

`CoiledSpring.glb` is generated by this repository's `make_spring.py` under the
repository license. It contains actual helix geometry, a 13-joint skin and native
compression/bending clips. It is a reconstruction, not a recovered copy of an
unidentified spring asset from an earlier session.
