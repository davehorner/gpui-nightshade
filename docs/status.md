# Implementation status and remaining work

The default executable now runs the trunk viewer core inside the GPUI-owned window. `--cube` retains the presentation demonstrator; `--model=PATH` loads into the actual viewer world.

Implemented this milestone:

- Reusable viewport inspection API with actual transport/adapter, effective visibility, fallback/error and metadata tied to the retained image. Shared pending frames preserve producer identity; unused parallel GPU-frame abstractions were removed. See [embedding API](integration.md).

- `ViewerCorePlugin` and `NativeViewerUiPlugin`, with the original `ViewerPlugin` composing both. Core startup and update schedules run without a retained UI runtime.
- Embedded composition with caller-owned arguments and no native Nightshade event loop or window.
- Bounded action submission and owned hierarchy, selection, material, animation, render settings and history snapshots. Existing viewer actions and native agent plugin are reused.
- A worker-owned full viewer frame lifecycle, loading/extraction/render hooks, continuous simulation and resize handling.
- GPUI hierarchy selection, transform/name fields, metallic/roughness, visibility/delete, primitive creation, undo/redo, exposure/grid/bloom and basic animation controls. Inspector fields apply on Enter.
- Material color/emissive/transmission/IOR and texture replacement/removal controls; light creation/properties, camera clipping/activation, playback speed/looping and history-aware Undo/Redo. See [viewer controls](viewer.md).
- Asset browser with local/Khronos/Polyhaven tabs, search, pagination, resolution controls and bounded native remote thumbnails. Live Khronos thumbnail display and card-to-scene Avocado loading verified. Local previews and broader download/dialog coverage remain unfinished.
- Animation blend duration and layer add/remove/weight controls, live ECS morph weights, skeleton toggle/joint count and held-clip action. AnimatedMorphCube layer/morph controls and SimpleSkin skeleton state verified live. Retargeting coverage remains incomplete.
- Rendering inspector tabs/dropdowns, atmosphere/effect/fog/focus/sun controls, native screenshot and GLB dialogs. Live menu-to-core and native PNG/GLB writes verified; skinned/animated GLB round-trip rendering passed.
- Trunk gizmo pointer routing with ordered edges, coalesced moves, active mode/snap state, capture-phase movement/release and rollback on cancel/focus/size changes. Live move/scale, out-of-viewport release, undo and GPU background picking verified.
- Retained native dock panels for Scene/Viewport/Inspector/Animation, drag-to-tab/split, resizing, panel zoom and reset layout. Live tab/reset preserved scene identity. Versioned layouts save explicitly or on normal close and restore panel arrangement, sizes and active tabs across launches; invalid files fall back to defaults. Native save/relaunch/close/corrupt-file checks and persistence regression tests pass.
- Dock-hidden and platform-window-hidden/minimized viewport presentation suspension with continued CPU scene service and explicit offscreen render jobs. Independent visibility sources prevent restoring a window from unhiding a dock tab. GPU regression verifies stopped presentation, hidden servicing and resume without host recreation. Native readback checks verified hidden edits/screenshots, selection preservation, model replacement, continued animation and minimized MCP edits followed by successful restore. Windows full-occlusion detection and shared-texture suspension stress remain unfinished.
- Native external-path drop bindings route one GLB/glTF/HDR/ZIP/FBX path to trunk's existing loader, with drag highlighting and rejected-drop status. Path/extension regression tests pass. The live editor displayed the test-folder Fox model and its animations after an Explorer drag attempt, although the desktop tool reported a coordinate error; repeatable automated external-drop coverage remains incomplete. Folder/bundle/texture-slot drops remain unfinished.
- Shared-GPU import retirement retains evicted D3D11 textures/views/owners until consumer completion, with producer-lease backpressure. Fresh full-editor runs pass 600/1,200 publications, model replacement, animation, and resize/minimize stress on the RTX 4080. Native blocked-completion eviction and ring-reuse regressions cover the corrected lifetime. Readback remains the default pending broader coverage. See [GPU validation](windows-gpu-validation.md).
- Deferred spawn registration fix: selection/rows/material/light state are read after queued ECS components are installed.
- Original native frontend startup, core edits/undo/snapshot ownership, light/camera history, native HTTP MCP round-trip and bounded frontend queue tests. Live MCP rename/selection was also observed in the rendering GPUI editor; a GPUI spotlight intensity edit applied with Enter was confirmed through MCP.

Validation: workspace check, tests and strict Clippy pass. A surface-free bundled DamagedHelmet load rendered 1,303 distinct colors in the initial headless check. The GPUI editor displayed its hierarchy and model, but the shared presentation run reported D3D device removal/HRESULT 0x887A0006. A fresh isolated Vulkan run also passed with 1,287 distinct colors, and a 120-frame run completed with 8,917 colors. Native GPUI validation confirmed textured model display, hierarchy selection, inspector population and primitive creation. The subsequent import-retirement correction passes repeated forced-shared full-scene runs on this adapter; broader shared stability remains unverified. The editor defaults to readback while this is investigated.

The previous cube milestones remain: surface-free rendering, asynchronous readback, Windows D3D12/D3D11 shared textures and fences, DPI coordinates, picking/outline, camera orbit/pan/zoom, GPUI overlay and independent multi-viewport display. Broader drivers, long stress and device recreation remain unverified.

Remaining viewer work includes complete PBR/texture controls and advanced camera/skeleton/retargeting coverage, local asset previews and broader catalog/dialog validation, broader rendering-mode validation, conversion UI, external-drop validation and folder/bundle/texture-slot drops, broader rotation/snapping and outside-window capture stress, full shortcut coverage and feature parity checks. The core still compiles upstream UI dependencies although it does not instantiate their runtime. Non-Windows GPU sharing, Windows full-occlusion detection, shared-world multi-camera views, HDR/color validation and detailed GPU timings remain unfinished.
